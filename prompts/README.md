# Prompt Examples Reference

This folder contains example prompts organized by category. Each person works in their own file to avoid merge conflicts.

## How to contribute

1. **Pick your file** — each contributor has their own file:
   - `carlos-examples.md` — Carlos
   - `friend-examples.md` — (your friend's name)
   
2. **Never edit someone else's file** — this prevents merge conflicts entirely

3. **Use the template below** for each example

4. **These are reference only** — never copy prompts directly to the platform. Use them as inspiration for the agents to generate original variations.

## Template

```markdown
### [Component Name]
**Category:** landing-pages | forms | dashboards | cards | headers | modals | tables | backgrounds | authentication | checkout | animations | footers
**Complexity:** simple | medium | complex
**Key elements:** [list the important visual/interactive elements]

**Prompt:**
[The prompt text that describes what to build]

**Notes:**
[What makes this good, what could be improved, patterns to learn from]
```
