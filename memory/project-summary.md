# Project Summary

## What This Is

Prompt Platform is a greenfield prompt marketplace application. Users discover, preview, and unlock high-quality AI prompts through an ad-gated access model. Content is generated by internal AI agents and curated by human reviewers before publication.

## Current State

The project is in early development (Phase 0 -- scaffold complete). The foundational infrastructure is in place:

- Next.js 15 App Router application with TypeScript strict mode.
- Prisma ORM with PostgreSQL database schema fully defined.
- Authentication scaffolded with NextAuth.js v4 and Prisma adapter.
- Docker Compose for local PostgreSQL.
- Vitest for unit testing, Playwright for E2E testing.
- ESLint and Prettier configured.
- CLAUDE.md and AGENT_RULES.md established for AI agent workflows.

## Tech Stack

| Layer | Technology |

## Key Domains

1. **Prompt Catalog** -- browsing, searching, filtering, and viewing prompts by category and tag.
2. **Preview System** -- showing representative output samples before unlock.
3. **Unlock Flow** -- ad-gated content access with provider-agnostic adapter pattern.
4. **Review Workflow** -- human approval pipeline with status lifecycle (DRAFT through PUBLISHED).
5. **Agent Pipeline** -- AI-powered prompt generation with skill-based execution.
6. **Admin Tools** -- review queue, prompt management, audit trail, agent run monitoring.

## Repository Structure

Single repo (not a monorepo). All source code lives in `src/`. Database schema in `prisma/`. Agent context files in `skills/`, `memory/`, `hooks/`, and `docs/`.
